Cobalt Backend is the Go service that powers Cobalt accounts, social features, cloud saves, game catalog data, discovery feeds, and the public game API.

It runs as one HTTP service with PostgreSQL or TessalDB, an identity provider, and optional metadata and object-storage providers. Feature modules can be enabled independently.

## What the backend provides

- Account registration, sign-in, sessions, profiles, password flows, and linked identities.
- Friends, presence, direct messages, invites, and WebSocket events.
- Cloud-save storage and per-game save settings.
- A game catalog, artwork processing, discovery feeds, prices, and Game Pass data.
- An API-key-protected `/v1` catalog API.
- Administrative tools and supervised external plugins.

<Note>
  The API is designed for Cobalt clients. Treat endpoint behavior and response fields as versioned application contracts, even where a route does not use the `/v1` prefix.
</Note>
