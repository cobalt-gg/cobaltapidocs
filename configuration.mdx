---
title: Configuration
description: Configure Cobalt Backend with environment variables and a runtime JSON file.
---

Cobalt reads required service settings from environment variables. Use `COBALT_CONFIG` to point to a JSON file for runtime behavior. Missing JSON fields use built-in defaults; unknown fields and invalid values stop startup.

## Required settings

| Variable | Description |
| --- | --- |
| `DATABASE_URL` | PostgreSQL-wire database connection URL. |
| `DATABASE_DIALECT` | `postgres` (default) or `tessal`. |
| `AUTH_PROVIDER` | `supabase` or `firebase`. |
| `SUPABASE_URL` | Supabase HTTPS project origin when using Supabase. |
| `SUPABASE_PUBLISHABLE_KEY` | Supabase publishable or legacy anon key. |
| `SUPABASE_SERVICE_ROLE_KEY` | Server-only legacy service-role JWT for Supabase. |
| `FB_KEY` | Firebase web API key when using Firebase. |

`PORT` defaults to `8080`. `BASE_URL` defaults to `https://app-api.cobaltlauncher.com`.

<Warning>
  Use the Supabase Session pooler on port 5432. Do not use the transaction pooler on port 6543: migrations require a session-level advisory lock and the service uses prepared queries.
</Warning>

## Runtime configuration

Start with the backend repository's `config/server.example.json`. A minimal local override might look like this:

```json
{
  "http": {
    "app_host": "localhost:8080",
    "public_host": "localhost:8080",
    "origins": ["http://localhost:3000"]
  },
  "modules": ["auth", "social", "catalog", "discovery", "saves", "playtime", "admin", "public"]
}
```

Set `COBALT_CONFIG` to the absolute or working-directory-relative path of this file. `DB_MAX_CONNS`, `DB_MIN_CONNS`, and `COBALT_MODULES` override the matching JSON values.

## Important groups

| Group | Controls |
| --- | --- |
| `http` | Request concurrency, timeouts, host names, browser origins, compression, logs, proxy trust, and rate limits. |
| `database` | Connection pool size, connection lifetime, startup timeout, and whether migrations run at startup. |
| `modules` | Enabled feature modules. |
| `jobs` | Background job enablement and intervals. |
| `plugins` | Supervised external plugin processes. |

`http.trusted_proxy_cidrs` must contain only the immediate, trusted proxy networks. If it is empty, forwarded client-IP headers are ignored. Do not trust `X-Forwarded-For` or another forwarded header without a verified proxy boundary.

## Optional providers

Set the matching variables only when you need the associated capability:

- R2: `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET`, and `R2_BASE_URL`.
- IGDB: `IGDB_CLIENT_ID` and `IGDB_CLIENT_SECRET`.
- SteamGridDB: `STEAMGRIDDB_KEY`.
- IsThereAnyDeal: `ITAD_KEY`.
- Discord: `DISCORD_CLIENT_ID` and `DISCORD_CLIENT_SECRET`.
- Minecraft: `MICROSOFT_CLIENT_ID`, `MICROSOFT_CLIENT_SECRET`, `MICROSOFT_REDIRECT_URI`, and `MINECRAFT_TOKEN_KEY`.

Keep `MINECRAFT_TOKEN_KEY` stable when upgrading. It decrypts existing linked Minecraft refresh tokens.
