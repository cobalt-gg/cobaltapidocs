This index covers 131 method/path combinations in the reviewed backend. Parameters in braces are path segments. Read the linked feature page for field definitions, side effects, and errors. “Public” means no credential, not necessarily read-only.

Auth labels follow [Request conventions](/architecture). The six versioned placeholder routes are registered but return 501. Health routes have host rules and the WebSocket route upgrades the connection.
